Заметки, которые не мешают работать

Ни лент, ни досок, ни подписок. Только стикеры, которые лежат там, где вы их оставили.

Новая заметка за секунду

Нажмите Ctrl+Shift+N в любой программе — стикер появится сразу, не переключая окна.

Поверх всех окон

Заметка не прячется за браузером и редактором: список дел виден, пока вы работаете.

Поиск по всем заметкам

Ctrl+Shift+F находит нужную запись среди десятков стикеров и подсвечивает совпадения. Поддерживаются регулярные выражения.

Свой вид у каждой заметки

Двенадцать цветов фона, цвета текста, размер шрифта и ширина стикера — под задачу и настроение.

Автосохранение

Текст записывается сам, пока вы печатаете. Забыть нажать «Сохранить» невозможно.

Данные только у вас

Заметки лежат в локальном файле на вашем компьютере. Ни облака, ни учётной записи, ни интернета.

Экспорт и перенос

Сохраните все заметки в JSON или HTML и перенесите на другой компьютер вместе с базой.

Живёт в трее

Значок рядом с часами: создать заметку, показать все сразу, открыть настройки или выйти.

Запуск с Windows

Одна галочка в настройках — и стикеры на месте сразу после включения компьютера.

Частые вопросы

Вопросы и ответы

Stickio действительно бесплатная?

Да. Программа бесплатна целиком: нет платных версий, подписки, рекламы и регистрации. Учётная запись не нужна, интернет для работы не требуется.

Где хранятся заметки?

Только на вашем компьютере, в файле %LOCALAPPDATA%\Stickio\notes.db. Заметки никуда не отправляются, облака и синхронизации нет. Рядом автоматически создаются резервные копии базы.

Заметки пропадут при выключении компьютера?

Нет. Текст сохраняется сам, пока вы печатаете, и не теряется при закрытии программы или перезагрузке.

Нужны права администратора для установки?

Нет. В установщике можно выбрать установку для одного пользователя — тогда программа встанет в личную папку и права администратора не понадобятся.

Можно перенести заметки на другой компьютер?

Да. В меню значка в трее есть экспорт заметок в файл JSON или HTML и импорт из него. Есть и копия базы целиком.

Антивирус насторожился при первом запуске. Это опасно?

Нет. Программа не подписана платным сертификатом, поэтому антивирусы иногда проверяют её внимательнее обычного. Установщик можно сверить по контрольной сумме SHA-256, указанной ниже, проверить на VirusTotal или посмотреть исходный код — он открыт.

Можно посмотреть исходный код?

Да, код открыт: github.com/strimer86/Stickio. Лицензия MIT — можно читать, собирать самому и использовать в своих проектах. Там же видно, что программа не делает ни одного сетевого запроса.

Есть версия для macOS или Linux?

Нет, Stickio работает только в Windows 10 и Windows 11.

Как удалить Stickio?

Как обычную программу: «Параметры» → «Приложения» → «Установленные приложения» → Stickio → «Удалить». При удалении спросят, стирать ли заметки.
